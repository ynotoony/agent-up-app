# 调研（research）

## 架构

- 本目录保存调研、对比和 spike 报告，回答"我们当时知道什么"；它是 `../adr/` 决策的证据链末端。
- **写完必须归档**：以结论收尾，归档后不再修改；观点变化 = 写新篇并互相引用，不覆写旧篇。
- 没有结论的调研是未完成的 spike，不许归档。
- 后台研究 agent 产出的带引用 Markdown 也落这里，同样以结论收尾。

## 目录清单

| 名字 | 地位 | 功能 |
| --- | --- | --- |
| `README.md` | 层索引 | 归档规则与报告模板。 |
| `<YYYY-MM>-<slug>.md` | 调研报告 | 一项调研的证据与结论。 |

## 报告模板

```markdown
# <YYYY-MM> — <调研标题>

**问题**：要回答什么。

**证据**：来源与关键事实（带引用/链接），只留决策相关部分。

**结论**：推荐什么，一段话；写不出结论就不能归档。

**被引用**：哪个决策采用了本结论（ADR 编号，事后补记）。
```
