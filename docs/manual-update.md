# Manual updates

AgentUp does not auto-update.

1. Download a new build from the same channel you used to install.
2. Quit AgentUp.
3. Replace the app. Do not delete project directories.
4. Open AgentUp and load the project. Facts stay in each project's `.agentup/`.

Uninstalling the app does not delete `.agentup/` folders.
